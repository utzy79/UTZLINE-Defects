**v1 (2026-10-09):** a new app. Andrew: *"Management dashboard. Variations & RFI register. Progress claims. Defects & handover. all as seperate apps"*; defects typed in, dropped on the plan and imported from the builder's list: *"both"*.

- **Defects** (DF-001, DF-002 … per project): level, room, joinery item (picked from the room's items), where exactly, the defect, trade, from (ours / the builder's list + their ref), raised, fix by, assigned to (anyone, from the names list or typed), notes. **Open → Fixed** (our fix done, waiting on the builder) **→ Closed** (signed off); **Not ours** for another trade's. **Fixed and Closed need an "after" photo.** Reopen any time. **Overdue** = open past *fix by* (red, counted on the project list).
- **Photos:** + Before photo / + After photo (the tablet's camera or a file), made smaller on the device (1600 px JPEG), kept in `PDFs\Defects\<Level>\<Room no.>\DF-001\`, shown on the defect with who and when.
- **Plan:** the project's floor plans (from UTZLINE Projects, `Project Saves\Floor Plans`) with the joinery items as grey dots and every defect as a numbered pin (red open, blue fixed, green closed). **+ Drop a defect**, tap where it is: a new defect opens with that level, the nearest joinery item and its room filled in, and the pin kept. Tap a pin to open its defect. Pan, pinch / wheel zoom, + / − / Reset view.
- **Import builder's list…** (CSV or Excel): the columns are found by their headings (ref, level, room / location, description, trade, due) and can be changed; a trade filter (e.g. "joinery") leaves out other trades' rows; "Level 1" finds L1, "G.07" finds "G.07 Bath"; when the room has one joinery item it is picked; a builder's ref already imported is never imported twice, so the next list can be dropped in as it is.
- **Print (PDF)** — the register by level; **Print report with photos** — each defect with its details and before / after photos, to hand to the builder or the site team; **Export Excel**. All of the current filter (status, level, assigned, search).
- **Handover** tab — the **O&M handover pack**: for every item (one level or all), the newest **approved shop drawing** of each drawing (`PDFs\SD\...\<drawing>\Approved`), the newest **as-built job note** (`PDFs\AS BUILT\...`) and the newest **Manufacture / Delivery / Install ITP** PDFs (`PDFs\ITPs\...`), then the **defects register**, behind a cover with the contents and page numbers. *Check what's there* lists, per item, what was found. The pack opens and is kept in `PDFs\Handover\` (made again the same day: "(2)", never over the first). A damaged or password-protected PDF is listed on the cover as not included.
- **Where it keeps things:** `<Project>\Project Saves\Defects\<Level>\<Room no.>\DF-001\<yy-mm-dd hh-mm-ss-mmm> - <initials> - <create|edit|assign|status|photo>.json` — one small file per change, never overwritten, never deleted; the folder is chosen when the defect is raised. The shared code (`shared/defects`) is what the Management Dashboard reads.
- Sign-in at the start (same name + PIN as every app; app code **Defects** in the Users screen), Change folder needs an administrator PIN, works offline.
